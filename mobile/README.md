# DS Bot mobile

The DS Bot app for iOS and Android. It controls the Bot team that runs on your computer; nothing runs on the phone. The design is in [docs/plans/2026-10-24-mobile-app.md](../docs/plans/2026-10-24-mobile-app.md).

Pair the app with your computer by scanning the QR code in DS Bot's Settings → Phone. The encrypted link to the computer is in [../link](../link); run `npm ci` there too before you build.

## Run

Needs Node 22 or later. iOS needs Xcode on macOS; Android needs the Android SDK and an emulator or a device. Expo Go is not supported, because the app will use native modules.

```sh
npm ci
npm run ios          # build and open in the iOS Simulator
npm run android      # build and open in the Android emulator
npm run typecheck
```

`EXPO_PUBLIC_DSB_DEMO=1` skips pairing and fills the app with a demo team. It is only active when the flag is set while the bundle is built.

```sh
EXPO_PUBLIC_DSB_DEMO=1 npx expo start                       # demo data
npx expo run:android --device <emulator>                    # native build when deps change
```

`ios/` and `android/` are generated by the build and are not committed.

In the iOS Simulator the app keeps its pairing in the Keychain, which an unsigned build
cannot use: a build made with `CODE_SIGNING_ALLOWED=NO` (as in CI) stays on a spinner.
`npm run ios` signs the simulator build, so use it to run the app.

## Install on your own iPhone

Until the app is on TestFlight, you can build it and sign it with your own Apple ID.
You need a Mac with Xcode and the iPhone on a cable (or on the same Wi-Fi after the first
install).

1. In Xcode, open Settings → Accounts and add your Apple ID. A free Apple ID works; a
   paid Apple Developer account works too.
2. Pick a bundle id of your own, for example `com.yourname.dsbot`, and find your Team ID
   (Xcode → Settings → Accounts → your team). Then build:

   ```sh
   (cd ../link && npm ci)
   npm ci
   export DS_BOT_IOS_BUNDLE_ID=com.yourname.dsbot
   export DS_BOT_APPLE_TEAM_ID=<your Team ID>
   npx expo run:ios --device --configuration Release
   ```

   Pick the iPhone from the list. The Release build carries the app's code inside it, so
   it runs without your Mac.
3. On the iPhone, turn on Settings → Privacy & Security → Developer Mode (the phone
   restarts), then trust your certificate under Settings → General → VPN & Device
   Management.
4. Open DS Bot on the computer, go to Settings → Phone, turn it on and show the QR code.
   Scan it with the app. The iPhone's Camera app also opens the pairing link in DS Bot.

With a free Apple ID the install stops opening after 7 days; run step 2 again to renew
it (the pairing stays). With a paid account it lasts a year.

### Through SideStore

[SideStore](https://docs.sidestore.io) installs the app with your Apple ID and refreshes it
in the background, so a free Apple ID needs the computer only once. In SideStore, add the
source `https://raw.githubusercontent.com/BangyiZhang/DeepSeek-Bot/main/mobile/sidestore/source.json`;
new versions show up there as updates.

To publish a version: build the app unsigned for iPhone, put `Payload/DSBot.app` in a zip
named `.ipa`, attach it to a GitHub prerelease named `ios-v<version>` (a prerelease, so the
desktop app's update check, which reads the latest release, does not take it), then run
`node scripts/sidestore-source.mjs <ipa> <download URL> "<what changed>"` and commit
`sidestore/source.json`.

## Release

- Android: `.github/workflows/release.yml` builds and signs the APK.
- iOS: the account items, the archive/upload steps and the failure guide are in
  [docs/plans/2026-11-13-ios-release.md](../docs/plans/2026-11-13-ios-release.md).
  With the Apple account variables set, `npm run ios:archive` archives and exports
  `ios/build/export/DSBot.ipa`; `sh scripts/ios-archive.sh --upload` also sends it to
  TestFlight. `mobile-ios` in `.github/workflows/test.yml` builds the iOS project for the
  simulator on every change, unsigned.
