# 个人 fork：聊天界面与深浅主题

## 最终设计

- Mac 侧栏使用贴边纯色底、轻分隔线和独立的圆形工具按钮。主 Bot 入口保留头像与名称，角色文字没有嵌套标签框，选中项采用轻底色。
- 收起栏在非全屏时为 96px，容纳原生红绿灯；操作按钮保持 44px 点击区域，展开入口使用侧栏图标，徽标不超出选中背景。通过应用自己的网格变量保留聊天和右侧面板的独立轨道。
- 不改变系统窗口圆角，不增加原生桥，也不添加两侧悬浮外框。
- `glass.js` 只为标题、弹层等功能控件提供轻量网页材质与明确的圆形、胶囊形状。Mac 侧栏按钮和输入框使用主题实色。标题悬停入口使用无箭杆的 chevron，详情展开时反向。
- 浅色分隔线使用文字色 12% 混合，控件边框使用 20%；深色保留原有 8% / 15%。预设主题同步，避免设置主题后丢失可见边界。
- 减少透明度和增强对比度时使用实色回退，不对消息内容添加滤镜。

网页材质不等同于 AppKit / SwiftUI 原生 Liquid Glass。代码为项目自行实现，未复制第三方组件，未增加运行时依赖。

收起宽度以框架的目标轨道更新为准：将默认的 56px 目标替换成 96px，不等待收起栏 DOM 挂载，避免先收窄后扩宽。展开及右侧面板轨道沿用框架提供的值，全屏继续使用原有布局。

## 附件输入状态

上传附件时，输入框改为三行：附件预览、文字输入、底部操作按钮。附件插槽的 `display: contents` 不会生成布局盒，不能只用 `flex-basis` 分行；有附件时显式使用网格并恢复插槽的布局盒。删除最后一个附件后恢复紧凑单行布局。附件沿用项目自己的文件图标和主题色。

## 验证

插件单元测试、生成文件一致性检查、lint 和桌面端测试均通过。已在桌面应用检查浅色主界面、账户菜单、设置面板及收起栏，并通过设置切换深色检查后恢复跟随系统。
