# 个人 fork：键盘与浮层交互

用户要求按 `apple-design` 改善当前应用交互。沿用现有界面、红绿灯布局和模型路由，先完善反馈、空间关系和键盘控制。

- 搜索、设置和记忆弹窗接管 Tab 导航，关闭时将焦点交回入口。如果操作已把焦点交给另一个弹窗或输入框，不抢回焦点。
- 模型、工作目录及右键菜单使用同一焦点层级；菜单支持方向键循环、Home / End 和文字前缀定位。文本框保留编辑及输入法按键。
- 菜单的指针高亮与键盘焦点保持一致；菜单退出时立即释放键盘层级，避免退场动画吞掉下一次 Escape。
- 普通弹窗和按压使用无超调的弹簧，按下立即反馈，松开后自然复位。现有跟手高亮继续保留速度连续的弹簧。
- 右键菜单从指针位置展开，搜索弹窗沿进入方向退出。轻量浮层使用薄透材料，并响应减少透明度、增强对比度和减少动态效果的系统偏好。

改动仅使用插件自己的客户端组件、样式和浏览器 API，不修改 DSH。焦点行为有独立 DOM 回归测试；交互同时在 Electron 桌面版检查。
