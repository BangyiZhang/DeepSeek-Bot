# External image libraries

This source package distributes original software only. No ChineseBQB images or imported semantic catalog are included. The accompanying download tools can retrieve a user-selected library from its pinned upstream revision for local use. Public availability does not establish redistribution permission; obtain appropriate rights before distributing a combined package.

The renderer works with local library paths without a bundled catalog. Optional blob matching accepts an explicit fingerprints array of byte lengths and SHA-256 values through the integration options. Provisioning requires an explicit --library directory containing an index.json and its relative image files.
